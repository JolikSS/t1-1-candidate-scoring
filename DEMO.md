# Демонстрация проекта

Проект обрабатывает локальные архивы реальных документов из `data/vacancies.zip` и `data/resumes.zip`. Синтетический демонстрационный архив удалён. Исходные ZIP содержат резюме и не должны попадать в Git или публичные презентации.

## Показать работу в PyCharm

1. Откройте `run_project.py` и нажмите **Run**. Скрипт запускает MongoDB, импортирует архивы, затем поднимает API и интерфейс.
2. Откройте `http://127.0.0.1:8501`. Выберите вакансию из списка; список загружается из MongoDB.
3. Нажмите **Рассчитать рейтинг** без загрузки дополнительных файлов. Для демонстрации используется весь заранее импортированный набор резюме.
4. Покажите столбцы покрытия обязательных навыков и отдельного TF-IDF сходства. Не выводите имена, контакты или исходные PDF.
5. Для завершения запустите `stop_project.py` через **Run**. База и локальный обезличенный JSON остаются на диске.

Скриншот прежней версии и команды Neo4j из этой инструкции удалены: актуальная схема использует MongoDB и описана в [README.md](README.md).
