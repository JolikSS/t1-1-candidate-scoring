# Демонстрация локального интерфейса

1. Откройте этот клон в PyCharm и запустите `run_project.py` кнопкой Run. Дождитесь API и UI, откройте `http://127.0.0.1:8501`.
2. В разделе **Вакансии** найдите запись, раскройте требования. Для собственных требований заполните и явно сохраните новую вакансию; существующие записи UI не редактирует.
3. В разделе **Резюме** покажите поиск и карточку с профессиональными сведениями. При необходимости загрузите PDF/TXT/ZIP. Повторные файлы используют прежние ID, ошибки элементов показаны отдельно.
4. Отметьте несколько активных резюме и нажмите **Использовать отмеченные в рейтинге**. Проверьте выбранную вакансию и число кандидатов. Доступны также весь активный набор и текущая загрузка.
5. Нажмите **Рассчитать рейтинг**. Задача продолжается после обновления страницы. Одновременно выполняется один расчёт, повтор одного запроса не создаёт дубль.
6. В результате примените фильтры, измените сортировку, скачайте CSV и выберите 2–4 кандидатов для сравнения. Метрики независимы и не являются решением о найме.
7. В **Истории** откройте прошлый прогон и сравните два завершённых расчёта одной вакансии. Для старых записей снимки требований могут отсутствовать.
8. В **Резюме** можно скрыть отмеченные записи после подтверждения и затем восстановить их. Новые расчёты не включают скрытые документы, старые результаты сохраняются.
9. Остановите приложение через `stop_project.py` кнопкой Run. База сохраняется.

Все документы остаются локальными. Не публикуйте архивы, выгрузки и скриншоты с профессиональными сведениями без отдельного решения о приватности. OCR отсутствует, анонимизация эвристическая.
