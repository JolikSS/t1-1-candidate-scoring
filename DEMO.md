# Демонстрация

1. Подготовьте окружение, MongoDB и Neo4j по README.md.
2. Запустите run_project.py и откройте http://127.0.0.1:8501.
3. Выберите сохранённую вакансию или загрузите архив вакансий.
4. При необходимости загрузите архив резюме и нажмите «Найти кандидатов».
5. Проверьте итоговый Score, найденные навыки и статус «Недостаточно текста».
6. Повторите поиск без архивов: используется сохранённый активный корпус.

Порядок: неокруглённый TF-IDF cosine × 100, затем стабильный ID.
Шкала сходства 0..100 не является процентом пригодности.
Пустые и неоднозначные разделы требуют проверки; сканы без OCR не обрабатываются.
Для подтверждения качества нужен бенчмарк с ожидаемой релевантностью.

Новый API итогового Score, критических навыков и обратной связи HR можно
проверить через http://127.0.0.1:8000/docs по сценарию в docs/BACKEND.md.
Streamlit вызывает /score с тем же cosine-рейтингом, что и /scoring-runs.
