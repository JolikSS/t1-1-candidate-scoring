# Проверка бэкенда

Проверки выполнены 6 ноября 2026 года в ветке `feature/backend-api`.
Ниже сначала приведён первоначальный прогон MVP, затем расширенная проверка.

## Автоматические проверки

- `python -m unittest discover -s tests -q`: 207 тестов, успешно.
- Ruff для изменённых компонентов бэкенда, запуска и новых тестов: успешно.
- `git diff --check`: успешно.

Тесты включают прежние сценарии Parser, Scorer и Streamlit, а также новые HTTP
сценарии: загрузку настоящих PDF с текстовым слоем, защищённые и пустые PDF,
ZIP с частичными ошибками, лимиты файлов и HTTP, критические навыки, итоговый Score,
подмножество корпуса, скрытие резюме, снимки входов, решения HR, идемпотентность,
недоступность БД и дополнительного графа, перегрузку расчётов и старый API.

## Настоящие MongoDB и HTTP

Использованы MongoDB 8.0 во временном Docker-контейнере, Uvicorn и HTTP-запросы.
Каждый запуск `tools/verify_backend.py` создавал отдельную случайную БД
и удалял её после проверки. Подмена MongoDB в этой проверке не использовалась.

| Сценарий | Результат |
|---|---|
| 8 одновременных загрузок одного PDF | Сохранено одно резюме с одним ID |
| Загрузка PDF вакансии | Сохранены обязательные и желательные навыки |
| Пакет из 100 коротких PDF/TXT + расчёт | Успешно, около 0,802 с |
| Пакет из 500 коротких PDF/TXT + расчёт | Успешно, около 3,395 с |
| Пересчёт исключительно из сохранённых снимков | Рейтинг совпал |
| Повтор запроса оценки HR с тем же event_id | Возвращено исходное событие |
| Изменение оценки HR | История сохранена, экспорт отдаёт последнее решение |
| Изменение вакансии после расчёта | Старый снимок не изменился |
| Исключение скрытого резюме | Подтверждено |
| Совместимый /score без Neo4j | Подтверждено |

Команда для повторения:

```bash
python tools/verify_backend.py --mongo-uri mongodb://127.0.0.1:27017 --batch-size 500
```

Указанное время относится к коротким техническим документам и конкретному
окружению. Эти данные не подтверждают нормативы на реальных длинных PDF,
доступность 95%, качество на 20 профессиональных направлениях или качество
калибровки весов. Для этого нужен отдельный размеченный набор реальных пар.
Проверка нового зеркалирования на настоящем Neo4j отдельно не выполнялась;
его отказ проверен через тестовый адаптер.

## Расширенная проверка

После добавления лемматизации и инструментов приёмки:

- `python tools/check_backend.py`: Ruff, форматирование и 232 теста — успешно.
- Лемматизация русского/английского текста проверена с сохранением отрицаний,
  технических выражений и совместимости прежнего профиля.
- Оценщик и подбор весов проверены на явно синтетических примерах, включая
  независимость выбора параметров от меток test. Рабочие веса по ним не менялись.
- Мониторинг проверен на успешных пробах, недоступном сервере, пропусках
  наблюдения, сохранении и повторном чтении журнала.

Настоящие MongoDB 8.0, Neo4j 5.26 Community и HTTP/Uvicorn:

| Сценарий | Результат |
|---|---|
| 8 одновременных загрузок PDF | Одно сохранённое резюме |
| Пакет из 500 коротких PDF/TXT, профиль с лемматизацией | Около 4,152 с на загрузку и расчёт |
| Синтетический PDF на 100 страниц | Около 3,581 с на загрузку и расчёт |
| Новый рейтинг, оба профиля, и старый /score в Neo4j | Совпали с HTTP/MongoDB |
| Старый графовый рейтинг после нового расчёта | Сохранился |
| Рабочий сценарий 20 направлений с вручную заданными навыками | Успешно |
| Остановка API | Мониторинг обнаружил недоступность |
| Перезапуск API | История расчётов и решения HR сохранились |
| Короткое успешное окно мониторинга | meets_target=null, 95% не подтверждены |

Ветки CI настроены на Python 3.10/3.12 и настоящие сервисы. Фактический результат
удалённого запуска нужно смотреть в GitHub Actions/Checks; локальный прогон выше
выполнялся на Python 3.14.9, NumPy 2.5.4, sklearn 1.6.1, simplemma 1.2.0.

Новый профиль: weighted-coverage-tfidf-lemma-v2. Прежние версии остаются доступны.
Подробные команды и оставшиеся внешние условия: [ACCEPTANCE.md](ACCEPTANCE.md).
Эти результаты не заменяют оценку на реальном размеченном наборе или длительное
измерение доступности в целевой среде.
