# Разбор резюме и локальные эксперименты

## Рабочий парсер

Парсер правил `rules-2.0` сохраняет очищенные разделы и границы абзацев, проекты,
достижения, сертификаты, курсы и профессиональное описание. Навыки содержат
подтверждающие профессиональные фрагменты. Опыт разбивается по явным абзацам и периодам;
даты и явно обозначенная должность сохраняются без вычисления стажа.
Предупреждения обозначают отсутствующие поля и неоднозначность, а не уверенность.

Коллекция `resumes` сохраняет совместимые поля для существующих API/UI.
`resume_parses` хранит версии очищенного разбора, справочника и диагностические
данные. Хеш результата предотвращает повторную запись одинаковой версии.
ID и скрытие сохраняются. Старые записи помечаются `legacy`, структура не
восстанавливается из предположений. Исторические прогоны не изменяются.

Повторный импорт существующего файла не заменяет его разбор автоматически.
Для явного обновления из исходного локального ZIP:

```powershell
python tools/reparse_resumes.py --archive data/resumes.zip
```

При отсутствии исходников доступен ограниченный повторный разбор имеющихся
очищенных полей: `python tools/reparse_resumes.py --allow-cleaned-fallback`.
Он помечается `cleaned_only` и не восстанавливает ранее потерянные сведения.
Новые загрузки не сохраняют исходники; существующие архивы не удаляются.

## Изоляция экспериментов

Создайте отдельное Python-окружение и установите `requirements-experiments.txt`
и зависимости приложения. Не устанавливайте экспериментальные версии поверх
окружения Streamlit: их диапазоны зависимостей могут различаться.

Модели, векторы и результаты храните вне клона, например
`A:\CandidateScoringData\experiments`. Они не считаются обезличенными только
потому, что являются векторами. Скрипт запрещает вывод отчётов и кеша внутрь клона.
Исходный текст, запросы и сырые ответы моделей в отчёты не входят.

## Сравнение извлечения

Официальная модель `Qwen/Qwen2.5-3B-Instruct-GGUF`, revision
`7dabda4d13d513e3e842b20f0d435c732f172cbe`, файл
`qwen2.5-3b-instruct-q4_k_m.gguf`. У модели лицензия Qwen Research:
перед применением вне локального эксперимента проверьте её условия.
Используется официальный `llama.cpp b11669`; модели и бинарники не входят в Git.

После проверки доступной памяти запустите сервер локально:

```powershell
llama-server -m A:\CandidateScoringData\experiment-runtime\qwen2.5-3b-instruct-q4_k_m.gguf --host 127.0.0.1 --port 8087 --ctx-size 8192 --parallel 1 --threads 8 --log-disable --no-cache-prompt --cache-ram 0 --offline
python tools/resume_experiments.py extraction --archive data/resumes.zip --limit 8 --llm --output A:/CandidateScoringData/experiments/llm-extraction.json
```

Исходный извлечённый текст передаётся только фиксированному loopback endpoint;
proxy-переменные не используются, редиректы отключены. Документ рассматривается
как данные. Ответ проверяется на схему и дословное подтверждение каждого поля,
затем очищается. Это обнаруживает неподтверждённые выдумки, но не доказывает
правильность трактовки подтверждённого фрагмента. Вход более 5500 токенов или
100000 символов отклоняется, обрезанный ответ не принимается.

Без LLM можно сравнить старые и новые правила на всём архиве:

```powershell
python tools/resume_experiments.py extraction --archive data/resumes.zip --limit 500 --output A:/CandidateScoringData/experiments/parser-corpus.json
```

## Семантическое сходство

После остановки LLM запустите:

```powershell
$env:HF_HOME='A:\CandidateScoringData\experiments\huggingface'
python tools/resume_experiments.py semantic --limit 20 --output A:/CandidateScoringData/experiments/semantic.json
```

`intfloat/multilingual-e5-base` закреплена на revision
`d128750597153bb5987e10b1c3493a34e5a4502a`. Расчёт CPU, нормализованные векторы
768 измерений, `query:` для вакансии и `passage:` для резюме. Фрагмент содержит
до 448 токенов, перекрытие до 64 внутри длинного абзаца; полный вход проверяется
на лимит 512. Кеш зависит от содержимого, префикса, revision и версии подготовки.
Повреждённый кеш пересчитывается. Для загрузки модели требуется 3 GiB свободной RAM.

Сравниваются максимум всех пар фрагментов и среднее лучших совпадений по
фрагментам вакансии, рядом сохраняются TF-IDF и покрытие навыков. Реальный
эксперимент использует три вакансии и первые N активных резюме в порядке ID.
Это фиксированная техническая выборка, не репрезентативная оценка найма.

Контрольные искусственные примеры изолированы от пользовательской базы.
Они проверяют перефразировки, разные языки, отрицания, перечисления и длинный
текст. Без экспертной разметки нельзя подтвердить улучшение реального рейтинга.
Ни LLM, ни E5 не подключены к рабочему скорингу и интерфейсу.
