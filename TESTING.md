## Исправления и проверка запуска

Лаунчер обновляет несовместимую версию Streamlit. Снимок большого прогона проверяется до записи на лимит MongoDB 16 MiB; при превышении API возвращает HTTP 413 с советом уменьшить выбор.

Даты MongoDB без часового пояса трактуются как UTC. Выбранный ID вакансии сохраняется при изменении вариантов списка. После перезапуска API и Streamlit последний рейтинг восстановился.

Основной экран просмотрен в тёмной теме при 1366×768 и 1920×1080, в светлой — при 1920×1080.

Полный снимок корпуса TF-IDF не хранится: воспроизводится просмотр сохранённых результатов, но повторный исторический расчёт на прежнем корпусе не предусмотрен.

## Ограничения проверки

- Загрузка файлов, дубликаты и повреждённый ZIP проверены через реальный HTTP API. Полный ручной проход загрузки через браузер не завершён.
- Браузер автоматически переводил часть уже русских подписей. Исходные подписи проверены AppTest; авто-перевод может искажать текст в конкретном профиле Chrome.
- Полный ручной проход фильтров, CSV, сравнения, скрытия и восстановления в браузере не подтверждён; эти сценарии проверены AppTest/API.
- Обновление страницы именно во время длительного реального расчёта и аварийное отключение рабочей MongoDB вручную не воспроизводились. Эти ветви проверены контролируемыми автоматическими тестами.
- Пиксельная проверка всех разделов в обеих темах на обоих разрешениях не является завершённой. Отдельные снимки основного экрана не заменяют полный проход.

## Эксплуатационные ограничения

Один процесс API и один фоновый расчёт одновременно. Очередь находится в памяти процесса, результаты/статусы — в MongoDB. После аварийного перезапуска незавершённые задачи помечаются ошибкой; повтор запускается явно. При недоступной MongoDB запись ошибки также может быть невозможна до перезапуска API после восстановления базы.

Снимки структурированных полей увеличивают объём базы; набор, который не помещается в документ MongoDB вместе с резервом под результаты, нужно разделить. Несохранённые черновики, ручной выбор и последняя загрузка относятся к сессии браузера; URL и сервер восстанавливают раздел, вакансию, активную задачу и последний прогон.

Анонимизация остаётся эвристической, OCR отсутствует. Алгоритмы скоринга и парсинга в этой доработке не изменялись. Пользовательские документы, JSON и снимки экрана не включены в Git.
