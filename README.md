# Frontend: интерфейс скоринга резюме

## Назначение

Ветка содержит пользовательский интерфейс приложения на Streamlit. Интерфейс принимает требования вакансии и показывает результаты пакетного анализа резюме. Он обращается к REST API и не подключается к Neo4j напрямую.

## Что реализовано

- Страница скоринга с выбором вакансии из API или ручным вводом названия и обязательных навыков.
- Загрузка встроенного обезличенного архива из 70 резюме `data/workua_sample_70.zip` при расчёте. Архив не нужно выбирать вручную.
- Дополнительная загрузка PDF, TXT и ZIP с резюме. Сканированные PDF без текстового слоя не поддерживаются.
- Отправка выбранной вакансии, навыков и файлов на `POST /score`; список вакансий интерфейс получает через `GET /vacancies`.
- Таблица с покрытием обязательных навыков (Score), отдельным TF-IDF сходством, найденными и отсутствующими навыками.
- Отображение ошибок по номеру файла без показа исходного имени файла.

## Поток обработки

1. Интерфейс запрашивает у API сохранённые вакансии. Если список пуст, можно ввести вакансию вручную.
2. При нажатии «Рассчитать рейтинг» UI добавляет к загрузке встроенный ZIP и необязательные файлы пользователя.
3. API обрабатывает резюме и возвращает результаты; UI отображает обезличенные обозначения кандидатов.

Score — доля найденных обязательных навыков. TF-IDF сходство показывается отдельно и не меняет Score.

## Файлы ветки

- `ui/app.py` — Streamlit-страница, форма, вызовы API и отображение результатов.
- `ui/__init__.py` — пакет интерфейса.
- `images/` — каталог ресурсов интерфейса.

## Запуск

После объединения интерфейса с Backend, Parser, Scorer и Benchmark запустите весь проект через `run_project.py` в PyCharm. Отдельный запуск интерфейса возможен командой `python -m streamlit run ui/app.py`, если API уже работает на `http://127.0.0.1:8000` и архив находится в `data/`.
