# Backend: REST API и хранение в Neo4j

## Назначение

Ветка содержит серверную часть системы скоринга: FastAPI принимает вакансии и резюме, запускает парсер и скоринг, а затем сохраняет результаты в графовую базу Neo4j.

## API

- `GET /health` — проверка доступности API и подключения к Neo4j.
- `GET /vacancies` и `POST /vacancies` — чтение и сохранение вакансий с перечнем обязательных навыков.
- `POST /score` — приём резюме PDF/TXT и ZIP-архивов, анализ кандидатов и сохранение результатов.
- `GET /vacancies/{vacancy_id}/results` — получение сохранённых результатов для вакансии.

Для пакетного запроса предусмотрены пределы: не более 100 резюме, 20 МБ на резюме и 200 МБ общего объёма. ZIP читается в памяти; поддерживаются PDF и TXT. Неподдерживаемые и повреждённые файлы возвращаются как отдельные ошибки, не останавливая обработку всей партии.

## Хранение

`db/graph_store.py` управляет соединением и графом Neo4j. Используются узлы `Vacancy`, `Candidate`, `Resume` и `Skill`, а также связи `REQUIRES`, `HAS_RESUME`, `HAS_SKILL` и `SCORED_FOR`.

В базе хранятся случайные идентификаторы кандидатов и резюме, тип файла, навыки, вакансия, метрики и время расчёта. Исходный текст резюме, имя кандидата и исходное имя загруженного файла в граф не записываются.

## Запуск и остановка из PyCharm

- `run_project.py` — выбирает готовое Python-окружение `A:\CandidateScoringEnv`, если оно доступно; иначе устанавливает зависимости в выбранный интерпретатор. Затем запускает Neo4j через Docker Compose, проверяет готовность БД, поднимает API и UI и открывает браузер.
- `stop_project.py` — отдельный PyCharm Run-скрипт: завершает лаунчер и процессы API/UI, останавливает контейнер Neo4j и сохраняет данные базы.
- `.env.example` — шаблон локального пароля Neo4j. Файл `.env` с реальным паролем в Git не добавляется.

Чтобы запустить полный проект, выберите `run_project.py` в PyCharm и нажмите **Run**. Чтобы остановить его, запустите `stop_project.py` через **Run**.

## Файлы ветки

- `api/` — маршруты FastAPI, загрузка и обработка партий резюме.
- `db/` — Neo4j-драйвер, ограничения уникальности и операции чтения/записи.
- `docker-compose.yml` — контейнер Neo4j с постоянным Docker volume.
- `requirements.txt` — Python-зависимости приложения.
- `tools/` — пакет вспомогательных инструментов.
