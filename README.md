# Benchmark: обезличенный набор резюме для тестирования

## Содержимое

Ветка содержит `data/workua_sample_70.zip` — ZIP-архив с 70 разными обезличенными TXT-записями резюме, а также `data/WORKUA_SAMPLE_SOURCE.txt` с атрибуцией, лицензией и описанием обработки.

## Источник и лицензия

Исходный датасет — `KSE-RESEARCH-Group/Work_UA_resumes` на Hugging Face:

- Источник: https://huggingface.co/datasets/KSE-RESEARCH-Group/Work_UA_resumes
- Лицензия: Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0).

Набор предназначен для некоммерческого тестирования. При повторном распространении указывайте источник и лицензию.

## Обезличивание и ограничения

В подготовленных записях оставлены должность, опыт, навыки, языки и часть образования. Исключены идентификаторы и ссылки профилей, имена, возраст, город, зарплата, предпочтения занятости, статус ветерана, инвалидность, названия работодателей и учебных заведений, а также свободный блок дополнительной информации. Обнаруженные email, телефоны и URL удалены.

Это структурированные и переформатированные данные, а не оригинальные файлы резюме. Часть исходной разметки получена автоматически и может содержать ошибки. Датасет преимущественно украиноязычный и не является репрезентативной заменой резюме HeadHunter. Используйте его только для проверки приложения.

## Использование

После объединения с ветками Frontend и Backend приложение подставляет архив автоматически при нажатии «Рассчитать рейтинг». В CLI архив обрабатывается модулем `python -m scorer.benchmark` после объединения веток Scorer и Parser.

## Файлы ветки

- `data/workua_sample_70.zip` — пакет тестовых резюме.
- `data/WORKUA_SAMPLE_SOURCE.txt` — происхождение, атрибуция, лицензия и описание фильтрации.

Старые корневые генераторы синтетических данных удалены; данные в этом архиве взяты из опубликованного датасета и обработаны для тестирования.
