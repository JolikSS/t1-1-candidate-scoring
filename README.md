# Testing: проверка скоринга и демонстрационный сценарий

## Что проверяют тесты

Пакет `tests/` содержит `unittest`-проверки контрактов основных частей приложения:

- настройки демонстрационной вакансии и наличие 70 TXT-записей в ZIP;
- вычисление покрытия обязательных навыков и сопоставление алиасов;
- исключение навыка при простой отрицательной формулировке, например «без опыта Docker»;
- чтение обезличенного TXT-образца HH, отсутствие распознанного имени и ожидаемые 60% покрытия;
- разбор PDF/TXT-файлов из ZIP-загрузки и обработку неподдерживаемых файлов.

Обезличенный HH-файл для контролируемой проверки находится в `tests/fixtures/hh_public_resume_redacted.txt`.

## Как запустить

Из корня собранного проекта:

```powershell
python -m unittest discover -s tests -v
```

Тесты используют API, Parser, Scorer и архив из Benchmark, поэтому для полного прогона соответствующие ветки должны быть объединены в рабочую копию, а зависимости установлены из `requirements.txt`. Для этих unit-тестов запущенный сервер Neo4j не требуется.

## Ручная демонстрация

`DEMO.md` содержит шаги для ручной проверки UI: запуск приложения, выбор вакансии, автоматическая отправка архива и просмотр рейтинга кандидатов. Архив Work.ua и его атрибуция находятся в ветке `feature/benchmark`.

## Состав ветки

- `tests/test_project.py` — unit-тесты скоринга, парсера и пакетной загрузки.
- `tests/fixtures/hh_public_resume_redacted.txt` — обезличенный контрольный пример.
- `DEMO.md` — сценарий демонстрации приложения вручную.
