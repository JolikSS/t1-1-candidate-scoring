# Scorer: оценка соответствия резюме вакансии

## Назначение

Ветка содержит расчёт обязательных навыков и отдельную метрику текстового сходства. Она не принимает решения о найме и не объединяет показатели в один итоговый рейтинг.

## Метрики

### Score по навыкам

`analyze_skills(resume_skills, vacancy_skills)` нормализует названия навыков, убирает дубликаты и делит число найденных обязательных навыков на общее число требований:

`Score = найденные обязательные навыки / все обязательные навыки × 100%`.

Функция возвращает Score, найденные и отсутствующие навыки. Алиасы, например `Postgres`/`PostgreSQL` и `Python 3`/`Python`, сопоставляются по каноническим ключам.

### TF-IDF сходство

`calculate_text_similarity` считает сходство текста профессионального опыта и описания вакансии. Оно показывается отдельно и не изменяет Score. Если описание вакансии пустое или недостаточно информативно, значение сходства отсутствует.

## Поиск навыков

`scorer/skill_matching.py` содержит каталог алиасов и эвристики для простых отрицательных формулировок — например, «без опыта Docker». Это ограниченный набор правил, а не языковая модель: сложный контекст нужно проверять вручную.

## Конфигурация и CLI

`scorer/defaults.py` задаёт демонстрационную вакансию и её обязательные навыки. `scorer/benchmark.py` предоставляет функции расчёта и командный бенчмарк: он проверяет обезличенный HH TXT, обрабатывает ZIP с демо-резюме и выводит сводку.

После объединения веток полный бенчмарк запускается так:

```powershell
python -m scorer.benchmark
```

В модуле также доступны `analyze_skills` и `calculate_score` для использования API и тестами.

## Файлы ветки

- `scorer/benchmark.py` — покрытие навыков, CLI и контролируемые проверки.
- `scorer/skill_matching.py` — алиасы, нормализация и поиск упоминаний навыков.
- `scorer/text_similarity.py` — TF-IDF сходство текста.
- `scorer/defaults.py` — параметры демонстрационной вакансии.
- `scorer/__init__.py` — экспорт основных функций.

Для полного приложения модуль взаимодействует с Parser и использует набор из Benchmark.
